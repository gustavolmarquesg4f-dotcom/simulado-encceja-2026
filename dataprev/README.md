# Rota DATAPREV — Gestão de Serviços de TIC

Aplicação de simulados, revisão, plano cirúrgico e acompanhamento de desempenho para o perfil de Gestão de Serviços de TIC.

As 166 questões são autorais. A estrutura de pesos usa como referência a prova FGV/DATAPREV 2024 e deverá ser revisada quando houver novo edital oficial.
